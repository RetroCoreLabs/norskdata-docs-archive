# Document Storage

This directory contains per-document folders with text versions of Norsk Data manuals.

## Directory Structure

Documents are organized by category, matching the ND numbering scheme:

```
documents/
  software/
    60-general/
      ND-60.128/
        README.md                  # Auto-generated document card
        ND-60.128.03_EN.txt        # OCR/AI text version (uncompressed)
    61-nortext/
      ...
  hardware/
    06-peripherals/
      ...
```

Each document folder is named by its base ND number (subject + sequence).
Version-specific files live inside that folder.

## Text Files

Text files (`.txt`) are the primary deliverable stored in git:

- **Uncompressed** -- stored as plain text, not gzipped, for:
  - Direct MCP tool access (read file, no decompression needed)
  - GitHub web UI rendering
  - GitHub Pages search indexing
  - Readable `git diff` output
- **Naming convention**: `{ndNumber}_{language}.txt` (e.g., `ND-60.128.03_EN.txt`)
- **Size**: ~3 KB per page; a 245-page manual is ~735 KB
- **Estimated total**: ~150 MB for 200+ manuals (uncompressed), ~15 MB compressed in git packfiles

## Text Sources

Each text file has a `textSource` field in the catalog indicating how it was generated:

| Source | Description |
|--------|-------------|
| `ocr` | Generated by OCR tools (ocrmypdf, Tesseract) |
| `ai` | Generated by vision models from page images |
| `hand-curated` | Manually edited and verified |
| `imported-from-ndinsight` | Imported from NDInsight transcriptions |

Hand-curated NDInsight transcriptions are preferred over AI-generated text where available.

## No PDFs in Git

PDF scans are large (50-200 MB each) and are stored on Internet Archive, not in this repository.
The catalog tracks IA item IDs and sync status for each document.
